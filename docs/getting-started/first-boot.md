# First boot

Turn a fresh installation into your preferred baseline.

## Update the system

```sh
sudo apt update
sudo apt full-upgrade
```

## Add your essentials

Replace this example with the packages you actually use:

```sh
sudo apt install git curl vim tmux
```

## Continue documenting

Good first-boot documentation usually covers repositories, firmware, shell setup, SSH keys, backups, firewall rules, and desktop preferences. Keep secrets and machine-specific credentials out of this repository.
